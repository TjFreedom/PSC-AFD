# PSC / AFD Asset Upload Guide

Drop files into the correct folder below. After uploading, let Claude know
and the site will be updated to reference them automatically.

---

## 📁 assets/logos/
Brand logos for both companies.

| File name (recommended)         | What it's for                          |
|---------------------------------|----------------------------------------|
| `psc-logo.png` / `.svg`         | Pain & Sleep Therapy Center logo       |
| `psc-logo-white.png` / `.svg`   | White version (for dark backgrounds)  |
| `afd-logo.png` / `.svg`         | Center for Airway & Facial Dev logo    |
| `afd-logo-white.png` / `.svg`   | White version (for dark backgrounds)  |
| `network-logo.png` / `.svg`     | Combined / licensing program logo      |

**Preferred formats:** SVG (best quality at any size) or PNG with transparent background.
